About RoboControl

RoboControl is a browser dashboard for driving an ESP32 robot over Wi-Fi. It shows the front ultrasonic distance, battery level and connection state, and sends movement and utility commands to the robot.

Version Final 6. Built with plain HTML, CSS and JavaScript, so it runs from any folder with no installation.

Keyboard: arrow keys or W A S D to drive, Space to stop, L for lights, H for horn.
